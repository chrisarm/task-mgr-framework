## CONTRACT-002

**Title:** HUD-family extra-mark identity union + unlabeled named sibling
`rungs: None` (PRE-PR-3 gate between PR-2 and PR-3).

**Consumers:** FEAT-008 (identity union), FEAT-009 (unlabeled `rungs: None` +
live-shaped snapshot/exclude), FIX-010 (`wait_probe_lifted` via
`buckets_for_run_models`), FIX-012 remaining banner, PR-3 down-only walker /
TTL / inherit (must **not** loop until this contract is green; must **not**
reintroduce mapped-rung extra-mark).

**Pin timeline (pointer only — prose rewrite is DOCS-001):** until FEAT-008
code is green, `models set-tier claude frontier <opus>` is **harmful** (landed
extra-mark parks standard from a Fable HUD row). After FEAT-008: pin is
**optional, not required**. All-high / review clamp remains PR-3.

---

### Precise interface

```text
// usage.rs — HUD tokens (fable/opus/sonnet/haiku as API labels) live ONLY here.
// Family constants are used FROM model.rs (do not re-define).

fn canonical_model_for_hud_tier(tier: CapabilityTier) -> Option<&'static str>
// Frontier → FABLE_MODEL, Standard → OPUS_MODEL,
// CostEfficient → SONNET_MODEL, Cheapest → HAIKU_MODEL.

fn extra_mark_rungs_matching(
    models: &ResolvedModelsConfig,
    provider: Provider,                 // Claude only at call sites
    identities: impl IntoIterator<Item = &str>,
) -> Vec<(Provider, CapabilityTier)>
// OR: call once per member of I and union the results.
// Deduped rungs whose exact_model_for(provider, t) equals ANY member of I.
// Always include HUD primary R before / as part of the union.
// String equality only — not substring tier_of, not model_for clamp,
// NOT exact_model_for(mapped_rung) / exact_model_for(primary)'s configured model.
```

**Identity set construction** (after HUD maps `display_name` / `id` → rung R):

```text
I = { canonical_model_for_hud_tier(R) }          // ALWAYS — never omit
  ∪ { scope.model.id } when present              // also include when present
```

- **Do NOT** prefer `scope.model.id` over the family constant.
- **Do NOT** build a single `identity: &str` of “id or family constant.”
- Helper takes an identity **set** (iterator); call once per member and union.
- Output remains `Vec<(Provider, CapabilityTier)>`.
- Iterate **Claude** defined rungs only — do **not** iterate Grok/Codex.

**Unlabeled named siblings** (`ingest_named_sibling`):

```text
// seven_day_opus / seven_day_sonnet (and other named siblings without scope.model):
// - still ingested (NO allow-list of window names)
// - kind may still be weekly_scoped (explicit onLow rules still match)
// - rungs: None
// - must NOT call map_unlabeled_token / family-token-map onto standard/cost-efficient
```

**limits[] unlabeled ids** (row has model `id`, no `display_name`): still use
`map_unlabeled_token` (substring against configured model strings). That path
is for `limits[]` only — named object siblings without `scope.model` must not
use it.

**Landed holes this contract replaces** (do not keep):

1. `extra_mark_rungs(models, provider, primary)` comparing other tiers to
   `exact_model_for(provider, primary)` — Fable HUD + frontier→opus pin marks
   **standard**.
2. `ingest_named_sibling` calling `map_unlabeled_token` for weekly_scoped /
   rung-scoped named keys — `seven_day_opus` maps onto **standard**.

| Fixture | Expected `rungs` / apply |
| --- | --- |

| Opus HUD + `id: "claude-opus-5-SNAPSHOT"` + same frontier→opus pin | `{standard, frontier}` |
| Opus HUD, no pin | `{standard}` only |
| Unlabeled named `seven_day_opus` / `seven_day_sonnet` (no `scope.model`) | ingested; `kind` may be `weekly_scoped`; **`rungs: None`** |
| Live-shaped `live_shaped_oauth_json()` evaluate+apply, factory `tierFallback` | unavailable `{frontier}` only; factory **Proceed** (mixed standard work continues). Must include snapshot/exclude assertions — apply-only without snapshot/exclude is known-bad |
| HUD token literals (`fable` / `opus` / `sonnet` / `haiku` as API labels) | **only** in `usage.rs` — REVIEW grep fails if copied into `quota.rs` / `model.rs` / `engine.rs` |

---

### Invariants

1. `I` is **always** the family constant **plus** `scope.model.id` when present.
2. Always include HUD primary R in the marked set.
3. Claude rungs only (no Grok/Codex iteration).
4. Match via string equality of `exact_model_for` against any member of `I` —
   not substring `tier_of`, not `exact_model_for(mapped_rung)`.
5. Named siblings without `scope.model` never call `map_unlabeled_token` for
   `rungs`.
6. `limits[]` unlabeled ids (id, no display_name) still use `map_unlabeled_token`.
7. Engine / proto-channel language stays capability rungs
   (`frontier` / `standard` / `cost-efficient` / `cheapest`); model ids appear
   only at the ingest adapter boundary.

---

### Known-bad discriminators (contract / tests must reject)

1. Extra-mark via `exact_model_for(mapped_rung)` / comparing to primary's
   configured model → Fable HUD + pin marks **standard**.
2. Prefer `scope.model.id` over the family constant → Opus HUD id
   `claude-opus-5-SNAPSHOT` + pin fails to extra-mark **frontier**.
3. Single `identity: &str` of “id or family constant” instead of a set union.
4. Family-token-map `seven_day_opus` onto **standard** (or sonnet →
   cost-efficient).
5. Apply-only live-shaped fixture without snapshot / exclude assertions.

---

### Failure modes

| Cause | Effect |
| --- | --- |
| Missing family constant in `I` | Opus snapshot + pin hole (frontier not marked when config stores `OPUS_MODEL`) |
| Missing snapshot id in `I` | Only hurts if config stored the snapshot string (still include id when present) |
| Unlabeled named sibling mapped onto a rung | Mixed work quota-emptied (standard/cost-efficient falsely unavailable) |
| HUD tokens copied into `quota.rs` / `model.rs` / `engine.rs` | REVIEW grep fails; model ids leak into engine state |

---

### Alternatives considered (rejected)

| Option | Why rejected |
| --- | --- |
| (a) Prefer snapshot id over family constant | Kills Opus+pin extra-mark when HUD sends `claude-opus-5-SNAPSHOT` and config stores `OPUS_MODEL` |
| (b) Extra-mark vs mapped rung's configured model (`exact_model_for(R)`) | Fable HUD + frontier→opus pin parks **standard** — the PRE-PR-3 hole |
| (c) Drop `seven_day_*` from ingest | No allow-list; `kind` must still match explicit `onLow` rules; keep ingest with `rungs: None` |
