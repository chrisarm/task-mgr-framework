Run the autonomous agent loop against a PRD

Usage: task-mgr loop run [OPTIONS] <PRD_FILE>

Arguments:
  <PRD_FILE>
          Path to PRD JSON file

Options:
      --dir <DIR>
          Directory for task-mgr database files
          
          [env: TASK_MGR_DIR=]
          [default: .task-mgr]

      --prompt-file <PROMPT_FILE>
          Path to prompt file (default: <base>-prompt.md)

      --format <FORMAT>
          Output format

          Possible values:
          - text: Human-readable text output
          - json: JSON output for machine parsing
          
          [default: text]

  -y, --yes
          Auto-confirm all prompts

      --hours <HOURS>
          Time budget in hours (max 168)

      --verbose
          Verbose output

      --no-worktree
          Disable git worktrees (use branch checkout instead)

      --external-repo <EXTERNAL_REPO>
          Path to external git repo for commit scanning (overrides PRD value)

      --cleanup-worktree
          Remove the git worktree on loop exit (requires worktree mode)

      --parallel <PARALLEL>
          Number of tasks to run in parallel per wave (1-3, default 2)
          
          [default: 2]

      --no-auto-review
          Skip the auto-launched `/review-loop` Claude session after a clean run (default: auto-launch when the loop completed >=3 tasks)

      --auto-review
          Force-launch `/review-loop` even on small (<3-task) runs

  -h, --help
          Print help (see a summary with '-h')
